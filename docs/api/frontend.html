Vistas y JavaScript

Las vistas Blade están en resources/views; cada una inicia con un comentario {{-- --}} que indica su propósito, el controlador que la usa y las variables que recibe. Los estilos están en public/css/raiders.css y las interacciones en public/js/raiders.js.
