Rol

App\Models\Rol extends Illuminate\Database\Eloquent\Model

Rol de usuario del sistema.

Define los tres perfiles de acceso: Administrador, Vendedor y Cliente.
La autorización por rol se aplica con el middleware \App\Http\Middleware\EnsureRol.
