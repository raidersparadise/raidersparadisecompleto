Pedido

App\Models\Pedido extends Illuminate\Database\Eloquent\Model

Pedido de compra de un cliente.

Flujo de estados: pendiente -> programado -> en_curso -> entregado, o cancelado.
La lógica de creación y cambio de estado está en \App\Services\PedidoService.
